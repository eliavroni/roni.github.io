# Roni Eliav website

Hebrew site for Roni Eliav, occupational therapist and Cog-Fun therapist. Built with Astro and published to https://roni.eliav.dk by GitHub Pages.

- Blog posts: one Markdown file per post in `src/content/blog/`.
- Contact details and links: `src/data/site.ts`.
- Every push to `main` rebuilds and publishes the site automatically.
